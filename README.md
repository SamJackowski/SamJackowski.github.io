# SamJackowski.github.io

## Dataset
The data set I chose was the College ROI dataset located [here](https://github.com/thomasthinks/college-roi-data). This dataset shows the return on investment (ROI) for many colleges and degree programs. Some possible applications for this dataset include allowing high school students to better research colleges and majors in order to choose a major that is worth their while and will serve them well in life with a good salary, and not just put them in debt with no way out of the hole. 

## Data Science Book
The book I chose was *ggplot2 Elegant Graphics for Data Analysis* by Hadley Wickham. The URL can be found [here](https://github.com/hadley/ggplot2-book). The basic premise of this book is that is was written as an intro to ggplot2, a library in R heavily used for plotting figures. As a statistics major, I have used R heavily in many of my courses and ggplot2 was a very useful library that I think everyone should have familiarity with.
